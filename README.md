# Tonify Cash Simulator v0.2 — «касса против котла»

Синтетический мир из 200 000 артистов, построенный от трёх измеренных якорей и
провалидированный на них, прежде чем снимать новые кривые. Каждый параметр приколочен
к источнику из tonify-research vault.

## Запуск
```
python3 tonify_cash_sim.py   # numpy + matplotlib
```

## Параметры → источники
- T1: 87% артистов < 1000 стримов/год — Luminate (год 2024/25)
- T2: 2,6% артистов > $1000/год — Spotify Loud & Clear (259 700 из ~10M)
- T3: топ-0,28% артистов ≈ 50% стримов — CMA / Last.fm (Gini 0,72 по активным)
- Плэи на слушателя: median 5,16 / mean 21,21 — LFM-1b (vault)
- Ставка котла: $4,43/1000 (US, янв 2026) — Duetti; карман подписанного $0,0003 — манифест, цепочка лейбла
- Суперфаны: 1,5–1,9% аудитории → 29% выручки — SoundCloud FPR white paper (vault)
- Донат: median $5, lognormal σ=0,8; доля артисту 0,80 (blend 96,5% desktop / 67,5% mobile) — Stars
- Фрод: до 85% AI-стримов фродовые, $2 млрд/год — Beatdapp (vault)
- Логистика: минимум вывода $13 (1000 Stars), холд 21 день — Telegram
