# Публикация сайта на GitBook

Репозиторий — источник истины. GitBook только рендерит. Никакого редактирования
в вебе: правка идёт в репо → PR → синк.

## Как это устроено

```
docs/
  facts.py        66 фактов как пары (файл-источник, регулярка). Единственный мост
                  между репозиторием и сайтом. Факт не извлёкся → сборка падает.
  build.py        шаблоны + факты → готовые страницы. --check сверяет, что
                  закоммиченные страницы = результат сборки.
  gates.py        ворота приёмки G1–G3 (+G2.4 по сети). FAIL = не публикуем.
  _templates/     ИСХОДНИКИ. Правки вносить сюда.
  en/  ru/        СБОРКА. Правки руками сюда бессмысленны — затрутся.
  g4-cold-reader.md  эталон и протокол теста холодного читателя.
```

Цифру на странице набрать руками нельзя: G1.1 находит любое число, которого
нет ни в фактах, ни в белом списке (годы, библиография чужих работ). Правка
любого текста:

```bash
# 1. правим docs/_templates/<lang>/...
python3 docs/build.py       # пересобрать
python3 docs/gates.py --net # ворота
```

## Что нужно сделать в GitBook (только владелец аккаунта)

У аккаунта, к которому подключён MCP, **нет ни одной организации** — создать
пространство, включить синк и настроить домен из сессии невозможно. Шаги:

1. **Организация и два пространства.** Создать организацию, в ней коллекцию
   `Tonify Research` и два пространства: `EN` и `RU`.

2. **Git Sync для каждого пространства.** Настройки → Git Sync → GitHub →
   `ProximaCA/tonify-sims`, ветка `main`:
   - пространство EN → директория `docs/en`
   - пространство RU → директория `docs/ru`

   `.gitbook.yaml` уже лежит в каждой из них — GitBook возьмёт `SUMMARY.md`
   как оглавление и `README.md` как главную.

3. **Направление синка — только из GitHub в GitBook.** В настройках Git Sync
   выключить обратную запись (`Bi-directional` → off). Это и есть G5 в
   предпочтительном виде: веб-редактирование отключено, значит расходиться
   нечему. Если оставить двусторонний синк — G5 требует проверить, что правка
   в вебе доезжает до репо коммитом.

4. **Переключатель языков.** Настройки коллекции → Variants: EN — основной,
   RU — вариант. Переключатель появится в шапке автоматически.

5. **Глоссарий.** Страница `GLOSSARY.md` синкается как обычная. Автоподсветку
   терминов включает GitBook (Settings → Glossary → включить для пространства),
   после чего термины со страницы подсвечиваются в тексте с всплывающей
   подсказкой.

6. **Домен.** Settings → Domain. После настройки — прислать URL, чтобы вписать
   ссылку в `README.md` репозитория (последний пункт DoD).

## Проверка после синка (G5)

- Открыть любую страницу — числа на месте, фигуры грузятся из `raw.githubusercontent.com`.
- Изменить строку в `docs/_templates/en/README.md`, пересобрать, запушить —
  страница в GitBook обновилась.
- Если двусторонний синк оставлен включённым: отредактировать страницу в вебе
  и убедиться, что в репозитории появился коммит.
