## L1: тождество отношения и условия выигрыша UC

**Зачем это.** Для принятой матрицы можно точно определить, какие артисты получат больше при смене PR на UC. Вес каждого слушателя в таком расчёте равен его доле в прослушиваниях данного артиста; обычное среднее по людям этот расчёт не заменяет.

**Что это значит.** Точное сравнение требует всей матрицы или вычисленных из неё взвешенных средних аудитории. Нишевость, число слушателей или неоднородность сами по себе не определяют победителя. Для каждой принятой матрицы рассчитываются оба правила и проверяется общий бюджет; направление перераспределения не закладывается в цель генератора.
