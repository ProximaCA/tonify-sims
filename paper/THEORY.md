## 2. Формализация

**Мир.** Конечные множества: артисты i ∈ N, слушатели u ∈ U, |U| = U.
Матрица плэев p = (p_iu) ∈ ℤ₊^{N×U} за период (год; целочисленность плэев
используется в §5.2 — при вещественных time-weighted плэях см. границу
p_iu/P_u ≤ 1 ⟹ UC_i ≤ W·A_i, верную на всём ℝ₊). P_u = Σ_i p_iu.
**Допущение A1 (несущее, найдено red team):** каждый платящий подписчик
слушает: P_u ≥ 1. Молчащие подписчики (P_u = 0) исключаются из ОБОИХ пулов;
на реальной платформе их кошельки сидят в pro-rata-пуле, но не имеют адресата
при UC — без A1 нулевая сумма (b) ломается ровно на W·U_sil, а все отношения
UC/PR получают множитель U_act/U_tot (контрпример §7). Судьба молчащего
кошелька — живой вопрос реальных UCPS-внедрений, не техническая деталь; P_i = Σ_u p_iu — плэи артиста; T = Σ_u P_u = Σ_i P_i; P̄ = T/U —
средняя интенсивность. Кошельки равные: W > 0 нетто с подписчика в пул
(нормировка B&MT «подписка = 1»); пул R = U·W. Аудитория артиста
A_i = |{u : p_iu > 0}|. Статусы допущений — как в SPEC §1: равенство кошельков
= measured-приближение (одна цена подписки), матрица p фиксирована
(учётная рамка; эндогенность поведения — §4 B4).

**Три механизма как операторы, income: ℝ₊^{N×U} → ℝ₊^N.**

- **PR (pro-rata):** PR_i = R · P_i / T = U·W·P_i/T. В sim1: inc = s·rate
  (rate — внешний якорь; связь — §3, абзац «Связь с u*»).
- **UC (user-centric):** UC_i = W · Σ_u p_iu / P_u. Кошелёк каждого делится
  внутри его собственных плэев (единственное ядровое правило по B&MT Thm 2).
  Sim1 считает mean-field аппроксимацию E[p/(p+o)] — это оценка E_w, не
  двудольный граф; тождества ниже точные, аппроксимация — вопрос сходимости.
- **DIRECT:** каждый слушатель аудитории — суперфан независимо с вероятностью
  σ; суперфан платит k платежей размера G (i.i.d., E G = ḡ, все моменты
  конечны — lognormal чека удовлетворяет); артист удерживает τ.
  D_i = τ · Σ_{f=1}^{S_i} Σ_{t=1}^{k} G_{f,t}, где S_i | A_i ~ Bin(A_i, σ).
  E[D_i | A_i] = τ·σ·k·ḡ·A_i. В нотации SPEC: σ = SF, ḡ = MG, τ = take.
- **Контракт** — мультипликативный слой ПОСЛЕ правила: income_signed = ρ ·
  income_indep, ρ = LABEL_PASS = 0.06772 (derived, SPEC §1).

Обозначения: u — индекс слушателя ЗДЕСЬ; u* сима — параметр кошелька
(«прочее прослушивание», SPEC §1), не слушатель. Суперфан-доля всюду σ (= SF
в SPEC); символ s зарезервирован за стримами, как в SPEC §2.

Все леммы — утверждения об операторах при фиксированной p. Что они НЕ
утверждают: равновесных эффектов (изменение правила меняет p — Lei 2023),
эффектов на общий размер пула, welfare-утверждений.

## 3. L1: тождество отношения — ДОКАЗАНО (тождество; следствия (b)–(d) доказаны; (a) исправлено)

**Теорема 1 (тождество).** Для любого артиста i с P_i > 0, при равных
кошельках:
  UC_i / PR_i = E_{w^i}[ P̄ / P_u ],
где w^i_u = p_iu / P_i — распределение плэев артиста по его слушателям.

*Доказательство.* UC_i/PR_i = [W Σ_u p_iu/P_u] / [U W P_i/T]
= (T/U) · Σ_u (p_iu/P_i) · (1/P_u) = P̄ · E_{w^i}[1/P_u]. ∎

**Каноническая форма (AM/HM-разложение).** Обозначим m_i = E_{w^i}[P_u]
(среднеарифметическая интенсивность аудитории под плэй-весами) и
H_i = 1/E_{w^i}[1/P_u] (среднегармоническая). Тогда
  UC_i / PR_i = P̄ / H_i = (P̄ / m_i) · (m_i / H_i),
и m_i/H_i ≥ 1 всегда (AM ≥ HM), с равенством ⟺ P_u константна на носителе
w^i. **Отношение распадается на уровень × дисперсию:** «лёгкая» аудитория
(m_i < P̄) помогает через первый множитель; разнородная аудитория помогает
через второй ВСЕГДА.

**Следствие (b) — нулевая сумма (доказано, связка к B&MT).**
Σ_i UC_i = W Σ_u (1/P_u) Σ_i p_iu = W Σ_u 1 = U·W = Σ_i PR_i. Оба правила
делят один пул; UC — чистое перераспределение: Σ_i (UC_i − PR_i) = 0.
(Budget balance каждого правила — B&MT 2025; связка в одну строку — здесь.)
Без A1 (молчащие кошельки в PR-пуле) равенство ломается ровно на W·U_sil,
а судьба молчащего кошелька при UC требует отдельной спецификации —
см. §7, находка L1-high.

**Следствие (c) — кроссовер (общий случай; типовой — Alaei Props 2, 8).**
UC_i > PR_i ⟺ E_{w^i}[P̄/P_u] > 1 ⟺ H_i < P̄: артист выигрывает от UC
⟺ гармоническое среднее интенсивности его аудитории (под плэй-весами) ниже
среднепопуляционной интенсивности. На типовых популяциях (артист j, типы i,
λ̄ = Σ_i q_i λ_i): UC_j ≥ PR_j ⟺ Σ_i q_i π_ij (λ_i − λ̄) ≤ 0 —
конвенция границы согласована с §1.1 (у Alaei et al. (2022) нестрогое
предпочтение pro-rata при ≥ 0) — verified численно на
5000 инстансов (Фаза 0). Общий случай — следствие Теоремы 1 в одну строку.

**Следствие (d) — премия за дисперсию (Йенсен) — ДОКАЗАНО.**
Фиксируем уровень: m_i = P̄ (аудитория типичной средней интенсивности).
Тогда UC_i/PR_i = m_i/H_i ≥ 1 с равенством ⟺ интенсивность аудитории
вырождена. Любая дисперсия интенсивности ВНУТРИ аудитории строго повышает
UC-доход относительно PR при том же среднем уровне. Направление ошибки
интуиции «UC помогает нишевым»: помогает не нишевость сама по себе, а
(i) лёгкость и (ii) РАЗНОРОДНОСТЬ слушателей.

**Следствие (a) — совпадение правил: ИСПРАВЛЕНО. Наивная версия ложна.**
Достаточность тривиальна: P_u ≡ P̄ ⟹ UC = PR покомпонентно. ОБРАТНОЕ НЕВЕРНО.
*Контрпример:* один артист, два слушателя, p = (10, 20): P_1 = 10 ≠ P_2 = 20,
но UC_1 = 2W = PR_1 (весь пул в обоих правилах). *Критерий (доказан):*
UC_i = PR_i для всех i ⟺ вектор c, c_u = 1/P_u − U/T, лежит в ядре матрицы
p (как оператора строк): p·c = 0. Однородность интенсивности — частный случай
c = 0. Экономически: правила совпадают, когда никакой артист не «экспонирован»
на отклонения интенсивности — либо интенсивность однородна, либо экспозиции
всех артистов на неоднородность взаимно сокращаются.

**Связь с u* сима (важно, чтобы не путать).** L1(c) — внутренний кроссовер
(оба правила делят ОДИН пул). Sim1 сравнивает UC с pro-rata, заякоренным
ВНЕШНЕЙ ставкой $4.43/1000 (D3), поэтому u*(ps = 0.40) ≈ 14 146
(8 731 / 21 371 при ps = 0.25 / 0.60) — калибровочный кроссовер,
совпадающий с внутренним в точке, где внешний якорь равен внутренней ставке
пула. Тонкость: мир sim1 имеет W_u ∈ {0, W} (PAID_SHARE = 0.40), поэтому
мост идёт через W_u-обобщение из пункта (i) ниже, сохраняющее структуру
тождества, а не через Теорему 1 в узкой формулировке. Оба кроссовера
легитимны; в тексте различать.

UC_i/PR_i = E_{w^i}[W_u/P_u] / (Σ_u W_u / T) — структура сохраняется,
«интенсивность» заменяется на «плэи на доллар» P_u/W_u; при W_u ≡ W
редуцируется к Теореме 1. (ii) Артисты с P_i = 0 — отношение не определено,
исключены. (iii) Слушатели с крошечным P_u взрывают 1/P_u? При целых плэях (домен §2)
P_u ≥ 1 ⟹ 1/P_u ≤ 1; безотносительно целочисленности p_iu/P_u ≤ 1 ⟹
UC_i ≤ W·A_i — выплата ограничена всегда, паталогий нет.

## 4. L2: инвариантность прохода — ДОКАЗАНО (тривиально по построению) + четыре условия слома

**Лемма 2 (две части — red team развела их принудительно).**
(2a) *Инвариантность отношения доходов.* Для любого оператора пула F,
ПРИМЕНЯЕМОГО НА УРОВНЕ АРТИСТА, и мультипликативного контракта строго ниже
по потоку (income_signed = ρ·F_i(p)): income_signed/income_indep = ρ
независимо от F — на домене F_i(p) > 0 (на носителе F_i = 0 оба дохода
нулевые, отношение не определено; пороговые правила B3 обнуляют целые
когорты). *Доказательство:* ρF/F = ρ. ∎ Уровень применения — несущее
допущение, а не педантизм: при нелинейном F, применённом к КАТАЛОГУ
получателя платежа, инвариантность ломается (канал B6 ниже).
(2b) *Инвариантность MVA.* MVA_signed(F)/MVA_indep(F) = 1/ρ ⟺
F⁻¹(V/ρ) = F⁻¹(V)/ρ — обе минимальные аудитории лежат на одном луче
однородности (V — порог годового дохода; в контрпримерах ниже V = $1 200/год,
c = PL·rate). Линейность income_F(A) ДОСТАТОЧНА, но НЕ необходима (второй
проход red team: строго возрастающий лог-периодический
F(A) = A·(1+0.1·sin(2π·ln A/ln(1/ρ))) нелинеен вдоль всего пути роста, но
даёт 1/ρ при всех V — слово «только» первой редакции ОТОЗВАНО). Для PR и
mean-field UC сима линейность выполнена — ×14.8 внутри sim1 корректен. Для
правил с порогами и бустами критерий ломается: *контрпример red team* —
artist-centric с бустом ×2 выше A₀ = 15 000 (Deezer-механика):
MVA_indep = 12 772 (небустованная ветвь), MVA_signed = 94 296 (бустованная),
отношение 7.38 = 1/(2ρ) ≠ 14.77 — при том что отношение ДОХОДОВ при каждом
фиксированном A остаётся ровно ρ.

Содержание: **реформа правила не может тронуть контрактный разрыв ДОХОДОВ
(2a — всегда); разрыв MVA она тронуть может (2b — только для линейных по A
правил)** — бустовое правило сокращает разрыв минимальной аудитории вдвое,
не меняя разрыва доходов ни на цент. Формулировка PAPER «контракт против
правила» выживает в терминах доходов безусловно, в терминах MVA — с
оговоркой линейности. Это формализация эмпирической регулярности Pedersen (2020):
доля лейбла не сдвинулась при сменах правила.

**Условия слома (каждое — именованный канал, где ρ перестаёт быть
мультипликативной константой):**

- **B1 — эндогенный ρ.** ρ = ρ(F): лейбл перезаключает условия под новое
  правило (переговорная сила зависит от структуры выплат). Эмпирика пока
  ПРОТИВ слома (Pedersen 2020 — доля стабильна), но канал открыт; тест — §9.
- **B2 — аддитивные компоненты.** income = ρ·F_i + a (авансы, фикс-фи,
  минимальные гарантии): отношение (ρF+a)/F зависит от F. Инвариантность
  выживает ⟺ контракт чисто мультипликативен.
- **B3 — порог выплаты (два режима, red team развела).** Порог θ ($13
  Stars). При ГОДОВОМ СГОРАНИИ остатка (цензура x·1{x ≥ θ}) разрыв ниже
  порога бесконечен: 0 против положительного. Механика sim1 — НАКОПЛЕНИЕ
  (months_to_13 = 13/(inc/12), SPEC §3.5): ничего не сгорает, слом — конечная
  задержка ×1/ρ во времени (signed на 2 000 стримов/год ждёт первой выплаты
  ~260 месяцев против ~18 у инди), превращающаяся в денежный разрыв только
  через дисконтирование, отток или смерть аккаунта. Логистика PAPER §4
  (89.9% signed ждут >10 лет) — следствие режима накопления, не цензуры.
  Инвариантность (2a) на потоках выплат ломается в обоих режимах, но
  по-разному: навсегда против во-времени.
- **B5 — гетерогенный проход по компонентам/рынкам (найден red team).**
  Реальный контракт задаёт РАЗНЫЕ ставки по компонентам дохода и рынкам:
  income_signed = Σ_m ρ_m·F_m. Эффективный проход ρ_i(F) = Σ_m ρ_m·w_im(F)
  зависит от правила через веса состава дохода, которые правило меняет
  механически (пример: ρ_US = 0.05, ρ_JP = 0.10; PR даёт артисту состав
  70/30 → ρ_eff = 0.065; UC перевешивает состав → ρ_eff другой). Скалярная
  инвариантность требует не «мультипликативности вообще», а ЕДИНОГО ρ на
  все компоненты.
- **B4 — поведенческая эндогенность (Lei 2023).** Смена правила меняет саму
  матрицу p (стимулы качества/выпуска): F и ρ действуют на РАЗНЫЕ p, сравнение
  перестаёт быть сравнением при прочих равных. L2 — учётная инвариантность
  при фиксированной p; равновесная версия — открытый вопрос (§8).
- **B6 — агрегация по получателю (найден вторым проходом red team).**
  (2a) предполагает, что правило применяется на уровне артиста, а контракт —
  ниже по потоку. Реальный лейбл лицензирует КАТАЛОГ: нелинейное F,
  применённое к каталогу лицензиара с внутренним сплитом
  income_i = ρ·F(A_каталог)·w_i, даёт эффективный проход
  ρ·F(A_каталог)·w_i/F_i(p), зависящий от F. Инвариантность выживает ⟺ F
  аддитивен по артистам (PR аддитивен; пороговые и бустовые — нет).

**Статус: (2a) доказано (уровень артиста + F_i > 0); (2b) — точный критерий
F⁻¹(V/ρ) = F⁻¹(V)/ρ; линейность достаточна, не необходима; вне критерия —
опровергнуто (контрпример выше).** Гипотеза брифа «найти условия слома»
закрыта конструктивно: B1–B6.

## 5. L3: действие на хвост и атом в нуле — ДОКАЗАНО (при явных условиях)

Предпосылка: аудитории (эквивалентно стримы, s_i = PL·A_i) имеют правильно
варьирующий хвост P(A > x) = x^{−α}L(x), α > 1 (в мире sim1 α = 1.4 —
assumed, ворота T3; эмпирическая оговорка Spierdijk & Voorneveld — §1).

**5.1 PR: линейный оператор — хвост сохраняется.** PR_i = c·A_i (c = PL·rate):
линейное масштабирование сохраняет правильную вариацию и индекс α (тривиально).
Контрактный слой ρ — ещё одно умножение: индекс не меняется (Breiman/JM 4.2
даже не нужен — константа). Gini положительной величины при масштабировании
инвариантен (Лоренц не двигается — Fellman: g(x)/x = const).

**5.2 UC: хвост сохраняется при несопряжённой интенсивности.**
UC_i = W·P_i·E_{w^i}[1/P_u] (Теорема 1). Множитель M_i = E_{w^i}[1/P_u]
ограничен: 1/P_u ∈ (0, 1] (целые плэи, A1). **Достаточное условие
(C, хвостово-условная концентрация — формулировка исправлена red team):**
для всякого ε > 0 P(|M_i − m*| > ε | A_i > a) → 0 при a → ∞, m* > 0.
Тогда UC_i = P_i·W·m*(1+o_p(1)) на хвосте и UC ∈ RV(α). Сходимость «по
вероятности по популяции» НЕ достаточна: контрпример red team — множитель,
дрейфующий только на хвосте (M_i = A_i^{−0.3} при A_i > 10⁶), проходит
популяционную сходимость (P(A > 10⁶) ≈ 4·10⁻⁹) и меняет индекс хвоста.
Достаточный примитив (исправлен вторым проходом red team: прежняя
формулировка «условная независимость пар + невырождение» условия (C) НЕ
влечёт): асимптотическая независимость M_i от A_i на хвосте с E[M^α] > 0 —
тогда индекс сохраняется напрямую по Breiman/JM даже без концентрации;
(C) — частный случай, который порождается, например, iid-парами (p_iu, P_u)
по слушателям, независимыми от A_i на хвосте (LLN внутри артиста). Ограниченность M_i ≤ 1 гарантирует одностороннее: хвост UC не
тяжелее хвоста внимания ни при какой зависимости; возможно только
утоньшение (M_i → 0 на хвосте). Точный инструмент для зависимых
произведений — Maulik–Resnick–Rootzén (2002). Статус: доказано при (C);
(C) измеримо (§9, пункт 3).

**5.3 DIRECT: хвост сохраняется сверху, снизу рождается атом.**
D_i = τ·Σ_{f≤S_i}Σ_{t≤k}G_{ft}, S_i|A_i ~ Bin(A_i, σ).

*(i) Верхний хвост.* S_i — биномиальное прореживание правильно варьирующего
счётчика: P(S > x) ~ P(A > x/σ) ⟹ S ∈ RV(α) (составная/прореженная
правильная вариация; JM Lemma 3.7 / Faÿ et al. 2006). Затем составная сумма
с лёгкими слагаемыми (lognormal чек: все моменты конечны, P(G > x) = o(x^{−α})):
P(D > x) ~ P(S > x/(kḡτ)) ⟹ D ∈ RV(α). Маршрут цитирования (уточнён red
team по первоисточникам): оба шага — JM Lemma 3.7(2), сверено дословно;
уточнённые асимптотики при независимости — Robert & Segers 2008; зависимость
слагаемых от счётчика — Denisov–Foss–Korshunov 2010. **Индекс хвоста дохода = индексу хвоста
внимания при ЛЮБОМ из трёх механизмов (PR — безусловно; UC — при (C);
direct — при чеке легче внимания, α_G > α).** Никакой механизм концентрацию
сверху не лечит — теоретический аналог Twitch −2.13 / Patreon-Pareto (§1).
*Оговорка-режим:* если чек тяжелее внимания (α_G < α — «киты», Tencent-режим
ARPPU ×20.6), хвост дохода наследует индекс ЧЕКА, не внимания: неравенство
внутри прямой экономики тогда управляется китами. Режим измерим (§9, п. 4).

*(ii) Атом в нуле.* P(D_i = 0 | A_i) ≥ (1−σ)^{A_i} (равенство при G > 0
п.н.; неравенство ≥ освобождает от предположения о положительности чека —
усиление red team). Для A_i ≤ 1/σ: (1−σ)^{A_i} ≥ (1−σ)^{1/σ} ≥ e^{−1}(1−σ)
≈ 0.36 (стандартная оценка; исходная версия этой строки содержала ложное
неравенство с делением вместо умножения — поймано и исправлено red team,
вывод «не менее ~трети» устоял). В калиброванном мире: 87% артистов < 1000
стримов/год ⟹ A < 48 при PL=21.21; при σ = 0.017: P(ноль) ≥ (1−0.017)^{48}
≈ 0.44 на ВСЕЙ массе T1. Пуловые механизмы атома не имеют: PR_i = c·A_i > 0
и UC_i > 0 при P_i > 0 — каждый стрим платит хоть что-то.

*(iii) Перемещение неравенства (формулировка-теорема).* Пусть q = E[(1−σ)^A] —
масса нулей direct. Разложение Джини с нулями G_direct = q + (1−q)·G⁺
(G⁺ — Джини среди положительных): три строки через разложение Σ|x_i − x_j|
по парам — нулевые пары дают 0, смешанные 2qn·n⁺μ⁺, положительные
2n⁺²μ⁺G⁺; частный случай двухгруппового разложения Джини (Dagum) с
вырожденной в нуле группой, overlap-член исчезает. Это ТОЧНОЕ тождество
(не приближение) под определением G = Σ_{i,j}|x_i − x_j|/(2n²μ),
эквивалентно для смеси qδ₀ + (1−q)F⁺; именно q + (1−q)G⁺, не (1−q)² —
подтверждено red team численно. Одновременно (i) даёт равенство верхних долей, но НЕ из одного индекса
(red team: одинаковый α не влечёт равных top-долей — константы хвоста могут
различаться): здесь константа хвостовой эквивалентности совпадает с
константой масштабирования среднего (E[D|A] = τσkḡ·A — та же λ, что в
P(D > x) ~ P(λA > x)), что и замыкает равенство top-x-долей при x → 0. Итого: **direct не снижает концентрацию сверху (тот же индекс)
и вводит экстенсивную маржу снизу (масса q вместо многих-малых-положительных);
неравенство перемещается из интенсивной маржи (дисперсия положительных
доходов) в экстенсивную (ноль/не-ноль)** — G_direct ≥ q при любом G⁺.
Что теорема НЕ утверждает: что G_direct > G_pool всегда — в мире с
G_pool = 0.97 сжатие лампового низа (один суперфан платит ≈ kḡτ независимо
от A) может компенсировать q; знак разницы Джини — вопрос калибровки, не
теоремы (проверка §10). Утверждение «не снижает, а перемещает» точно в этой
форме: индекс хвоста + атом + разложение. Статус: доказано.

## 6. L4: стохастическое доминирование — ДОКАЗАНО, результат СИЛЬНЕЕ гипотезы брифа

Сравнение при данной аудитории A: пул X_A = c·A детерминирован
(c = PL·rate — инди-сравнение; уточнение второго прохода red team: прежняя
скобка [ρ] молча выпадала из эквивалентностей ниже); direct
Y_A = τ·Σ_{f≤S}Σ_{t≤k}G_{ft}, S ~ Bin(A, σ).
Ожидания: E[Y_A] = τσkḡ·A; E-доминирование Y над X ⟺ τσkḡ > PL·rate ⟺
k > d* = PL·rate/(σ·ḡ·τ) — **в точности breakeven-сетка sim1
(0.38…1.25…6.31)**: теория воспроизводит циферблат, не переопределяя его.
Signed-случай — одной строкой: при контрактном слое c = PL·rate·ρ порог
масштабируется до ρ·d* ≈ 0.068 — signed-артисту direct выгоден по среднему
уже при k ≥ 1.

**Теорема 4 (полная блокировка доминирования).** Для любого A с
(1−σ)^A > 0 и X_A > 0 (положительность чека НЕ требуется — везде ниже
используется только P(Y_A = 0) ≥ (1−σ)^A; усиление red team):
(i) Y_A НЕ доминирует X_A по первому порядку (FOSD) — ни при каких σ, k, ḡ, τ;
(ii) Y_A НЕ доминирует X_A и по ВТОРОМУ порядку (SSD) — также ни при каких
параметрах, даже при E[Y_A] ≫ X_A;
(iii) X_A ⪰_2 Y_A (пул доминирует direct по второму порядку) ⟺
E[Y_A] ≤ X_A, т.е. ⟺ k ≤ d*;
(iv) при k > d* пара НЕСРАВНИМА ни в первом, ни во втором порядке:
ранжирование зависит от отношения к риску.

*Доказательство.* (i) Для x ∈ (0, X_A): P(X_A > x) = 1, но
P(Y_A > x) ≤ 1 − P(Y_A = 0) ≤ 1 − (1−σ)^A < 1. ∎
(ii) SSD-критерий против вырожденной X_A: нужно ∫_0^t F_Y ≤ ∫_0^t F_X =
max(0, t − X_A) ∀t. При t = X_A: LHS ≥ ∫_0^{X_A} P(Y=0) dz ≥
(1−σ)^A·X_A > 0 = RHS. ∎
(iii) (⇐) ∫_0^t F_Y = t − E[min(Y,t)] ≥ t − E[Y] ≥ t − X_A и ≥ 0 ⟹
∫_0^t F_X = max(0, t−X_A) ≤ ∫_0^t F_Y ∀t — это в точности X ⪰_2 Y.
(⇒) t → ∞: ∫_0^t (F_X − F_Y) → E[Y] − X_A ≤ 0. ∎
(iv) из (i)–(iii). ∎

**Интерпретация.** Гипотеза брифа («доминирования нет в нижнем хвосте»)
подтверждена и УСИЛЕНА: атом в нуле блокирует не только FOSD в углу, а ОБА
порядка целиком. Корректная рамка сравнения direct против пула — не
доминирование, а **среднее против риска**: direct платит премию по ожиданию
(при k > d*), покупаемую лотерейностью на малых аудиториях. Для
несклонного к риску артиста детерминированный пул при равных средних слабо
лучше при любой вогнутой полезности и строго — при строго вогнутой
(следствие (iii); уточнение второго прохода: линейная полезность вогнута и
даёт безразличие); требуемая премия
E[Y]/X − 1 растёт с вогнутостью и убывает с A (концентрация: заявленная в черновике
Хёфдинг-оценка exp(−2A(σ−σd*/k)²) ОТОЗВАНА red team — событие {Y < X} не
биномиально-пороговое при случайных чеках, численный контрпример нарушает её
в ~45 раз; корректная оценка Чернова: P(Y_A < X_A) ≤ inf_{t>0}
e^{tX_A}·(1−σ+σφ(t)^k)^A, где φ(t) = E[e^{−tτG}] < 1 — экспоненциальное
убывание по A сохраняется, точная константа другая). Рекуррентная
механика (Twitch k=12) снижает d*-разрыв в среднем, но атом (1−σ)^A не
трогает: против лотереи малых аудиторий работает только рост σ
(конверсия в суперфаны), не рост k.

**Статус: доказано.** Связка с sim1: fig2 (биномиальные суперфаны) +
§10 проверка 3 (атом 0.598 при A = 30) — численная тень пункта (i)–(ii).

## 8. Что осталось открытым

1. **Равновесная версия L1/L2.** Все результаты — учётные, при фиксированной
   матрице p. При эндогенном поведении (Lei 2023: качество; Alaei et al.:
   участие артистов и подписка пользователей) операторы действуют на разные p.
   Открыто: сохраняется ли Йенсен-премия (d) в равновесии.
2. **Знак ΔGini pool→direct в общем виде.** L3 даёт разложение и индекс
   хвоста, но знак разницы Джини зависит от калибровки (в мире sim1 —
   совпадение во втором знаке, сдвиг +0.002 в третьем, §10). Гипотеза: существует порог σ*(α, k), выше которого
   direct строго снижает Джини среди ПОЛОЖИТЕЛЬНЫХ доходов, никогда — полный.
   Не доказано.
3. **UC-хвост при сопряжённой интенсивности.** §5.2 даёт достаточное условие
   и границу сверху; точная характеризация «когда UC утоньшает хвост» через
   Maulik–Resnick–Rootzén — открыта. Измеримо (§9 п. 3).
4. **L4 для рекуррентного k с оттоком.** Теорема 4 берёт k детерминированным;
   churn суперфанов (sim3-мир) делает k случайным и коррелированным во
   времени — доминирование по порядкам на ПОТОКАХ доходов (не годовых суммах)
   не разобрано.
5. **Аксиоматика direct.** B&MT характеризуют PR и UC наборами аксиом; какая
   аксиома отличает direct (нарушение budget balance пула — он вне пула)?
   Возможная связка с claims problems: direct = правило с резервированным
   «нулевым иском». Не начато.

## 9. Эмпирический мост: какие величины нужны, чтобы теория предсказывала

Каждая лемма упирается в измеримую величину; всё ниже — оси MVP или готовые
внешние данные. Нумерация связана с «Объектом 3» (SPEC §1, строка k; PAPER §9).

1. **k (частота платежей суперфана)** — ось L4/breakeven; бенчмарки Twitch 12
   / Patreon 12 / медиана брейк-ивена 1.25. Меряет MVP напрямую.
2. **σ(A) — конверсия в суперфаны КАК ФУНКЦИЯ размера аудитории.** L3/L4
   принимают σ ⊥ A. Если σ убывает с A (у мегазвёзд конверсия ниже), атом
   меньше, хвост мягче; если растёт — наоборот. Тест: регрессия σ на log A
   по MVP-когортам.
3. **Сопряжённость интенсивности и размера** — corr(p_iu, P_u) по артистам
   разных размеров: закрывает условие §5.2 и решает, сохраняет ли UC хвост
   на реальных данных. Считается по любому полному лог-датасету (LFM-1b
   достаточно; вычислимо сейчас, без MVP).
4. **Хвост чека** — α_G из распределения донатов; решает режим §5.3(i)
   (киты против внимания). Меряет MVP; внешний прокси — распределение
   Superchat (Zhao et al. 2025).
5. **ρ(F) — тест эндогенности прохода** (B1): доля лейбла до/после смены
   правила на любой платформе, объявившей переход (Deezer artist-centric —
   естественный эксперимент; базлайн Pedersen 2020).
6. **Порог θ и его цензура** (B3): доля артистов под порогом $13 по когортам
   — уже посчитана в sim1 (89.9% signed >10 лет); эмпирическая валидация —
   выгрузка Stars-выплат MVP.

## 10. Численные проверки доказанного (не доказательства)

Скрипт: `theory_check.py` (seed=42, детерминирован; выход ниже воспроизводим).

1. **L1-тождество:** 200 случайных матриц (N ≤ 30, U ≤ 40, разреженность
   50%): max |UC/PR − E_w[P̄/P_u]| = 8.9e-16 (машинный ноль); нулевая сумма
   и AM≥HM — assert на каждом инстансе. Разложение P̄/H = (P̄/m)·(m/H) —
   тот же порядок ошибки.
2. **Контрпример (a):** p = (10, 20), один артист: интенсивности разные,
   UC = PR = 2W точно. Наивное «⟺» опровергнуто исполняемым примером.
3. **L4-блокировка:** A=30, k=4, σ=0.017: атом P(Y=0) = 0.598 (теория
   (1−σ)^30 = 0.598, совпадение в третьем знаке на 2M сэмплов);
   E[Y] = $11.24 против пула X = $2.82 — среднее в 4 раза выше, а
   **P(Y < X) = 0.598**: артист на 30 слушателях проигрывает пулу в 60%
   миров при четырёхкратном преимуществе в среднем. Второй проход red team:
   на полных 2M сэмплов P(Y<X) − P(Y=0) = 0 машинно — при этих параметрах
   проигрыш пулу это В ТОЧНОСТИ нулевой исход (положительная часть Y
   практически никогда не падает ниже X), что делает лотерейный аргумент
   чище (прежняя цифра 0.599 — шум 200k-подвыборки). Лотерея малых аудиторий —
   численно. При A=300 атом уже 0.006, при A=3000 — ноль: лотерейность
   умирает экспоненциально (Чернов, §6).
4. **Калиброванный мир (конструкция SPEC §2, seed=42):**
   q = E[(1−σ)^A] = 0.772 (измеренная доля нулей 0.777 — расхождение от
   целочисленного A в биноме); в T1-массе
   (A < 48) атом 0.88. **G_pool = 0.972 против G_direct = 0.974** —
   Джини совпадает во втором знаке (сдвиг +0.002 в третьем); тождество
   q_m + (1−q_m)·G⁺ = G_direct = 0.973844 с ИЗМЕРЕННОЙ массой нулей —
   машинный ноль расхождения (второй проход red team: прежний счёт
   подставлял теоретическое q в точное тождество и маскировал точность
   под приближение). Центральное следствие L3 в
   числах: смена pool→direct на калиброванном мире меняет суммарное
   неравенство лишь на +0.002 Джини — и полностью меняет его СОСТАВ: 77% артистов переходят
   из «многих крошечных положительных» в буквальный ноль, дисперсия
   положительных сжимается (G⁺ = 0.883 < 0.972), итог тот же. Неравенство
   перемещено, не снижено — конец аргумента.
