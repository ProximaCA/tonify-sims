## 0. Что строим

Одна формула с замороженными входами:

```
L(B, strategy) = B · (1 + rps)          # слушатели одного каскада, N=50k
σ*(B, k, c)    = 1200 / (L · k · c · τ) # доля, чтобы артист вышел на $100/мес
fee_month      = L · σ · k · c · 0.05 / 12
```

rps — опубликованная таблица sim2 experiment A (seed=42, k=2, p=p*=0.15).
Граф не пересобирается. k и чек — из emp2, если статус measured; иначе открытый
диапазон 0.38–1.25–6.31 и чек $6.89. Twitch k=12 в эту формулу не входит.

## 3. Фальсификатор

Если при хабовом посеве B=5 даже лучший открытый угол (k=6.31, чек $6.89)
требует σ* > 1.7% — совместная GTM+касса гипотеза неверна: каскад недостаточно
велик, чтобы калиброванная конверсия кормила артиста.

Обратное (случайный посев B=5 требует σ* ≫ 1.7% при том же k,c) — ожидаемый
контраст: без розжига хабов склейка не закрывается. Это не фальсификатор, а
содержание Finding 5–6 sim2, переведённое в доллары.

## 4. Честные ограничения

- Один трек, один каскад, нет конкурирующих каскадов, нет забывания (потолок sim2).
- σ не измерена на Telegram; полоса 0.6–1.7% — SoundCloud FPR / 97-2-1.
- Масштаб казны 50k → 1M — линейная плотность, не новая симуляция графа на 1M.
- k=4 в headline — рабочая точка milestone sim1/sim3, не closer диапазона.
