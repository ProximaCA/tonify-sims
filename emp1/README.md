# EMP 1 — редуцированный наклон b (прокси γ): знак измерен, уровень структурирован

Первое эмпирическое число спора — с честной структурой вместо точечного
заголовка. Измеряемый объект (переименован red team, находка C14): **b —
редуцированный наклон E[log p_iu | i] по log A_i** в панели Last.fm
2005–2014. Это ПРОКСИ структурного γ из sim4(c) (интенсивность при
фиксированном графе): наклон ловит и интенсивность, и селекцию графа, и
удержание. Спека и ворота: [SPEC.md](SPEC.md); запуск:
`python3 emp1/gamma_measure.py` (~45 с; данные в emp1/raw/, в гит не
входят — источники ниже).

## Результат (панель Last.fm 2005–2014; все ворота G1–G4 PASS)

**Знак: b > 0 — железный.** Не флипается ни в одном из разрезов: два
датасета × два оценщика, 27 комбинаций порогов, оба окна учёта, обе группы
юзеров, все хвостовые срезы; знак-контроль E3 положителен везде; плацебо
(пермутация аудиторий) даёт −0.0006 ≈ 0.

**Уровень: одного числа не существует** — и это содержательный вывод:

| Разрез | b_E2 (user-FE; SE двусторонняя CGM) |
|---|---|
| BeyMS, полная панель (~10 лет), бленд 50/50 | +0.101 ± 0.004 |
| — группа mainstream | +0.160 ± 0.004 |
| — группа beyond-mainstream | +0.023 ± 0.004 |
| — окно: календарный 2012 | +0.068 ± 0.005 |
| — окно: один месяц (2013-03) | +0.048 ± 0.011 |
| — голова: локальный наклон при A≥50 / A≥200 | +0.135 ± 0.008 / +0.232 ± 0.022 |
| — голова A≥1000 (16 артистов — шум) | +0.76 ± 0.53 |
| — сетка порогов p_min×A_min×u_min (27) | [+0.071; +0.104] |
| 360K (top-50 на юзера) | +0.044 ± 0.002 |
| BeyMS, усечённый до top-50 (фальсификатор G3) | +0.041 ± 0.004 |

**Три структурных факта** (red team, все воспроизведены независимо):

1. **Наклон — это удержание, не интенсивность.** Разложение по
   таймстемпам: b[log p] = +0.101 = b[длительность пары] +0.254 +
   b[плэи/день] **−0.154**. Слушатели крупных артистов слушают их ДОЛЬШЕ,
   но РЕЖЕ в день. Для месячного UC-учёта (реальные пулы месячные)
   релевантный наклон ≈ +0.05, вдвое меньше панельного; для sim4
   (лайфтайм-панельная PL=21.21) панельный +0.10 консистентен.
2. **Бленд 50/50 не идентифицирует уровень.** Пул BeyMS — конструкция
   датасета: mainstream-юзеры дают +0.160, beyond — +0.023. Популяционный
   уровень требует перевзвешивания по реальному распределению
   мейнстримности — вилка [+0.02; +0.16].
3. **Наклон выпуклый: у головы он круче.** Локально при A≥200 b ≈ +0.23.
   Для вопроса «какой доле топа выгоден user-centric» релевантен именно
   хвостовой наклон (~+0.2–0.3), не глобальный (+0.1).

**Фальсификатор G3:** усечение BeyMS до top-50 сдвигает b с +0.101 до
+0.041 — практически точно к 360K (+0.044): расхождение датасетов —
целиком эффект обрезки. Предсказание SPEC v0.1 о направлении («вверх»)
опровергнуто фактом (обрезка задирает уровень, плющит наклон) — CHANGELOG
v0.3.

**Мост к sim4:** оценщик прогнан на собственном DGP sim4(c) на реальном
графе (recovery: γ=0 → −0.000; γ=+0.1 → +0.084; γ=+0.3 → +0.260):
ceil-дискретизация съедает ~16% наклона, фактор инверсии 0.84 ⟹
панельному b = +0.101 соответствует **модельное γ ≈ +0.12**. В sim4
подставлять +0.12 (центр) и ~+0.3 (голова), не сырое +0.1.

## Что это значит для спора о user-centric

В датированной форме: в панели Last.fm 2005–2014 сопряжение
интенсивности с размером было слабо положительным глобально (b ≈ +0.1,
через удержание) и заметно положительным на голове (локально ≈ +0.2–0.3).
На sim4-шкале (γ=0 → UC выгоден 37% артистов, треть топа; γ=+0.3 → 53%,
топ 3.6%) реальный мир НЕ сидит в одной точке: для массы артистов — ближе
к γ≈+0.1, для головы — ближе к γ≈+0.3, где топ от user-centric почти
никогда не выигрывает. Направление «перераспределение от головы при
UC-реформе сильнее, чем при γ=0» — гипотеза до прогона sim4 с γ=+0.12 и
+0.3 (кандидат в следующий шаг), не следствие теории. Сегодняшний
(2026) уровень b может отличаться — эпоха данных доалгоритмическая; это
довод отдать измерение MVP, не против измерения.

## Датасеты (честно)

LFM-1b и LFM-2b официально сняты с раздачи (лицензия; страница JKU,
проверено 2026-08-14). Использованы сохранённые снапшоты:

- **LFM-BeyMS** — Zenodo 10.5281/zenodo.3784765 (Kowald, Lex & Schedl
  2021, EPJ Data Science): курируемый сабсет LFM-1b, 4,148 юзеров с
  полными историями, 16,687,363 события, 110,898 артистов. Отбор
  50/50 mainstream/beyond-mainstream — не случайная выборка (см.
  структурный факт 2). Полный 3.3GB-архив докачан диапазонными запросами
  (Zenodo дросселировал одиночное соединение до 64 KB/s), склеен и сверен
  с официальной контрольной суммой Zenodo (md5
  009f9e2104ce7566425de55060751b7b — совпадение бит-в-бит);
  dataset/events.csv извлечён штатным unzip из проверенного архива.
- **Last.fm-360K** — снапшот Celma (2010), зеркало
  archive.org/details/lastfm-dataset-360K: 359,349 юзеров, топ-50
  артистов на юзера, срез 2008.

## Ограничения

Last.fm — скробблеры, не стриминговая касса; демография смещена; отбор
BeyMS нерандомный (факт 2); b — редуцированная форма, не структурное γ
(конфаунд экспозиции: у крупных артистов длиннее каталожная жизнь и окно
пересечения с юзером — окно-чувствительность это ловит); эпоха 2005–2014;
левое усечение на p=1 (33% пар) — в сетке G4; точность ±0.004 —
сэмплинговая, доминирует систематика состава выборки и определения окна.

## Красная команда (обвинение → вердикт → действие)

Полный проход: 3 атакующих (эконометрика / код / интерпретация), 18
обвинений, 18 подтверждено независимым воспроизведением, 0 отклонено.
Главное: точечный заголовок «γ = +0.10 ± 0.003» ОТОЗВАН в пользу
структурированного результата выше; объект переименован в редуцированный
наклон b; в G4 добавлена ось p_min (честный интервал расширился до
[0.071; 0.104]); SE переведены на двустороннюю кластеризацию; «шесть
голосов знака» дефлировано до «E1/E2 × 2 датасета, E3 — знак-контроль»;
все утверждения о мире переведены в датированную форму. Механика
оценщиков (truncate_top50, фильтры, агрегация, E1/E2) воспроизведена
атакующими независимо — багов не найдено; плацебо-контроль вписан в
скрипт постоянно. Вердикты и числа — в этом README; протокол — в журнале
воркфлоу вне репо.
