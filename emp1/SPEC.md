# EMP 1 — редуцированный наклон b (прокси γ) по открытым логам · SPEC v0.4

Первое измеренное число спора: γ — та ручка sim4 (режим (c)), от которой
зависит знак реформы. В модели p_iu = base·(A_i/Ā)^γ, поэтому
E[log p_iu | i] = const + γ·log A_i: γ — наклон лог-лог регрессии
интенсивности пары на размер аудитории артиста.

## 1. Оценщики

- **E1 (сырой OLS):** на уровне артиста, mean(log p_iu) ~ γ·log A_i + c;
  SE — HC1. A_i = число юзеров пары, p_iu = плейкаунт пары.
- **E2 (within-user):** log p_iu, демин по юзеру (fixed effects), наклон по
  log A_i; SE кластером по артисту. Убирает состав слушателей (тяжёлые
  юзеры и у крупных, и в интенсивности).
- **E3 (непараметрический):** медианы log p по децильным бинам log A —
  fig17; Spearman по бинам как знак-контроль.

Фильтры: артисты с A_i ≥ 5 (шум единичных пар); плейкаунты ≥ 1;
юзеры с ≥ 10 артистами. Все пороги — в чувствительность.

## 4. Честные ограничения (заранее)

Last.fm — скробблеры, не стриминговая касса: p_iu это события
прослушивания, не деньги; демография Last.fm смещена (западные,
энгейджед); BeyMS-отбор нерандомный; артисты матчатся по id внутри
датасета (без дедупа имён между датасетами); γ в sim4 — про базу
интенсивности при ФИКСИРОВАННОМ графе, эмпирический наклон ловит и
селекцию графа (кто вообще слушает крупных) — это указываем, не прячем.
