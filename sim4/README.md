# SIM 4 — синтетическая двудольная матрица user×artist

Один субстрат — три режима назначения плэев; на нём пуловые механизмы
(pro-rata / user-centric) считаются буквально по THEORY §2, тождество L1
проверяется машинно, кроссовер UC/PR — знак в знак против H_i/P̄.

- **Вынужденное сопряжение (b):** corr(log Ã, log p̄_пары) = +0.047 —

- **Кроссовер на ИЗМЕРЕННЫХ γ** (v0.4; доля артистов с UC>PR, в скобках —
  среди топ-0.28%): γ=0 контроль независимости: **37.1% (33.9%)** ·

  тем реже им выгоден user-centric. Содержательно: при реальном
  сопряжении user-centric отбирает у головы ВЧЕТВЕРО жёстче, чем
  предсказывает удобная модель независимости (8.9% против 33.9% топа), и
  выгоден заметно большей массе артистов (45.6% против 37.1%). Прежняя
  симметричная ручка (−0.3) отозвана — отрицательное сопряжение
  эмпирически не наблюдается (emp1).
- **Атомы нуля (fig15):** direct — 75% артистов с нулём (σ=0.017, k=4);
  пуловые — 7% (пустая аудитория Ã=0, ноль у всех трёх механизмов).

## Красная команда (обвинение → вердикт → действие)

**R1. «Подпись fig15 противоречит коду».** Кламп `np.maximum(arr, 1e-4)`
вмазывал нулевые доходы в нижний бин, а подпись утверждала «в бины не
входит»; заодно структурный ноль пуловых (артисты с пустой аудиторией)
маскировался под атом direct. Вердикт: прав. Действие: нули исключены из
гистограмм, аннотация показывает оба атома раздельно.

**R2. «Детерминированные гифты — рецидив CRITIC §3».** Сумма подарков
заменялась матожиданием `S·k·E[G]` — хвост direct искусственно узкий,
ровно тот грех, за который v0.2 sim1 получил binomial-фикс. Вердикт: прав.
Действие: гифты сэмплируются лонормально поштучно (~1.5M дро).

**R3. «Мир не держит T3 на малом N».** Первый прогон N=5 000: доля стримов
топ-0.28% = 33.5% при пороге 40% — свойство мира, не бага механизмов
(хвост Парето на 14 артистах шумит). Вердикт: прав. Действие: N=20 000
(скан: 5k→33.5%, 10k→31.9%, 20k→40.3%), см. SPEC CHANGELOG.

**R4. «Стохастическое округление течёт через порог 1000».** Clip-масса
низкого яруса сидит ровно на 999 стримах; шум округления переталкивал
половину за порог — T1 падал до 84.4%. Вердикт: прав. Действие:
суммо-точное округление наибольших остатков, Σ по артисту == round(s_i).

**R5. «Контроль (a) не машинный ноль».** Float-накопление C/K_u давало
1.9e-12 > ворот 1e-12 на N=20k. Вердикт: прав — это арифметика, не
экономика. Действие: целочисленный контроль P_u ≡ 2048 (степень двойки:
p/P_u — точная двоичная дробь), G1 = 0.000e+00 ровно.

**R6 (viz-проверка). «Подпись оси X fig15 — каша».** Знаки `$` в строке
label matplotlib распарсил как mathtext — текст между ними слипся в
курсив («1упуловых»). Вердикт: прав. Действие: подпись переписана без
долларов; заодно лейбл насыщения головы «топ-14» (эпоха N=5k) заменён
на вычисляемый «топ-{top}».

**R7 (второй проход). «Насыщение 5.00 — циркулярная выборка».**
`np.sort(sat)[::-1][:top]` брал топ-56 по САМОМУ насыщению, не по стримам;
у реальной головы Ã/ℓ = 1.08, перепредставления нет. Вердикт: прав.
Действие: диагностика переписана на топ по ℓ, число в «Ключевых числах»
исправлено, нарратив отозван (см. выше).
